# 灰区行动 WEB 版（GREY ZONE OPS）

一个使用 **Three.js + 原生 JS** 实现的网页版第一人称战术射击游戏，还原战术撤离类玩法「烽火地带（危险行动）」的界面与玩法循环：**搜刮 → 战斗 → 撤离**。

> **在线体验**：https://ydm8964.github.io/grey-zone-ops/
> **源码仓库**：https://github.com/ydm8964/grey-zone-ops

> 零外部素材依赖：所有贴图（地面/混凝土/金属/锈蚀/天空）、干员立绘、物品图标、地图缩略图均为程序化生成（CanvasTexture / SVG），音效全部由 WebAudio 实时合成。

---

## 运行方式

需要通过 HTTP 服务访问（ES Module 跨域限制），任选其一：

```bash
# 方式一：Python
cd delta-force
python3 -m http.server 8099

# 方式二：Node
npx serve delta-force
```

然后浏览器打开 `http://localhost:8099`。

- 推荐使用 Chrome / Edge 等支持 WebGL 的现代浏览器
- 点击「进入战区」→「部署」→ 倒计时后进入战斗，点击画面锁定鼠标
- 若浏览器不支持 WebGL，会自动回退到大厅并给出提示（不会白屏崩溃）

## 已实现系统

### 大厅（6 个界面）
- **开始游戏**：3 种模式卡、4 张地图（零号大坝 / 长弓溪谷 / 巴克什 / 航天基地）、3 档难度（常规 / 机密 / 绝密，影响敌人强度与掉落）、出战干员与武器配装展示
- **干员**：11 名干员（红狼、蜂医、露娜、骇爪、牧羊人、威龙、疾风、深蓝、比特、银翼、蛊），职业筛选、技能展示、选中即生效
- **仓库**：16 种物资网格、品级色条、品级分布图、分类筛选、资产估值
- **交易行**：12 条行情，品类筛选 + 实时搜索、品级点、涨跌箭头、挂单热度条、持有资金统计
- **排行榜**：前三名领奖台（金/银/铜）、段位分、K/D 高亮、撤离率条
- **设置**：画面 / 音频 / 操作 / 游戏四个页签，滑条与开关

### 战斗（烽火地带）
- 程序化地图：大坝主体、10 栋建筑、20 集装箱、掩体墙、沙袋窝、油桶、哨塔；3 个撤离点（西侧闸口 / 北侧山路 / 东南码头）
- 部位伤害：头 / 胸 / 双臂 / 双腿 各自倍率与受击反馈，爆头特效
- 敌人 AI：巡逻 / 警戒 / 交战三态，走位拉扯、点射节奏、视线遮挡判定（空间网格 + slab AABB 加速）
- 护甲与血量系统、护甲板、医疗包 / 手术包 / 止血带、流血状态
- 背包 20 格 + 5 装备位、快捷栏、物资搜刮动画
- 15 秒站定撤离倒计时（移动会打断）
- HUD：小地图（雷达扫描 / 敌我标记 / 撤离点方位）、击杀播报、任务目标、伤害来源指示、准星扩散、命中反馈、计分板、结算界面

## 验证情况

- 大厅 6 界面 DOM 交互与渲染：Puppeteer 全量跑通，**0 报错**
- 战斗核心纯逻辑（碰撞高度判定 / 视线遮挡 / 网格下标一致性）：**单元测试 13/13 通过**
- 所用 THREE API 与 119 个 DOM id 引用：静态校验全部存在
- WebGL 缺失设备：部署按钮自动禁用并注明原因，不会进入倒计时后失败回退
- 3D 实机画面需在支持 WebGL 的浏览器中验证（开发沙箱无 GPU）

## 性能设计

| 优化项 | 说明 |
| --- | --- |
| 敌人部件合批 | 每个士兵 42~44 个 Mesh 按材质合并成 ~11 个（几何体预乘变换后拼合），绝密难度 37 敌时 draw call 从 ~2200 降到 ~1200 |
| 阴影相机跟随 | 阴影范围由整图 ±110 收窄到玩家身边 ±58，投影体约减少 3/4，阴影贴图 2048→1024 反而更清晰 |
| 远处 AI 降频 | 70m 外每 3 帧决策一次（用 3 倍 dt 补偿）；160m 外整体隐藏 |
| 小地图预渲染 | 建筑/掩体整幅俯视图只画一次，每帧仅一次 `drawImage`，绘制开销与方块数无关；刷新限流 30fps |
| HUD 脏值检查 | 血量/弹药/计时/体力/身体部位只在数值变化时写 DOM |
| 渲染分辨率 | 按画质预设取 0.8 / 1.0 / 1.5 倍，不再固定拉满 |
| 自适应降级 | 持续低于 42fps 达 3 秒 → 先关阴影，再降分辨率，并弹提示 |
| 共用材质缓存 | 地面/混凝土/金属等材质全局共享并标记 `userData.shared`，重开一局不会误释放 |

> **卡顿时的首选操作**：大厅 → 设置 → 画质 → 画质预设选「流畅」（0.8 倍分辨率 + 关闭实时阴影）。此前该选项只保存了数值、并未真正生效。

其余既有优化：

- 敌人视线检测：空间网格 + slab AABB，0.10–0.22s 降频
- 碰撞/弹道检测：网格 atRect 局部查询，替代全表扫描
- 沙袋、油桶等重复物件使用 InstancedMesh 合批
- 弹孔与血点独立上限管理，互不挤占；尸体、伤害飘字、材质纹理均在移除时彻底 dispose
